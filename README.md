[![PWA Ready](https://img.shields.io/badge/PWA-Ready-blue?logo=pwa)](https://web.dev/progressive-web-apps/)
[![License: Fan Content](https://img.shields.io/badge/License-Fan%20Content%20%2F%20Fair%20Use-orange)](#-правовая-информация-и-отказ-от-ответственности-disclaimer)

Интерактивная русскоязычная база знаний, каталог редких цветовых вариаций (**Shiny / Morph Deviants**) и симулятор лаборатории скрещивания (**Fusion Chamber**) для постапокалиптической онлайн-игры **Once Human**.

Сайт доступен прямо в браузере, адаптирован для ПК и мобильных устройств, а также работает в качестве прогрессивного веб-приложения (**PWA**) даже без постоянного интернет-соединения.

---

## 🌟 Основные возможности

- 🧬 **Полная энциклопедия девиантов:**
  - Детальные карточки для всех боевых, территориальных и крафтовых девиантов.
  - Точные точки поимки: Бункеры сдерживания (Silos), Монолиты, открытый мир, сценарии (*Novice*, *Manibus*, *The Way of Winter*).
  - Врождённые позитивные и негативные черты (Traits), рекомендации по выбору лучших перков.
  - Оптимальные условия содержания (Mood Boosters): свет, музыка, температура, окружение.

- 🌈 **Каталог редких морфов (250+ Shiny Deviants):**
  - Подробная галерея всех редких цветовых морфов и эксклюзивных скинов.
  - **Щелкунчик (22 морфа)**, **Дигби-бой (14 морфов)**, **Доктор Тедди (9 морфов)**, **Одинокий волк (8 морфов)**, **Кот из другого измерения**, **ZapCam** и все остальные спутники.
  - Интерактивная «примерка» скина прямо в карточке девианта.
  - Описание уникальных пассивных черт каждого морфа (*Золотой удар молнии*, *Инфразвуковая иллюзия*, *Лунный оракул*, *Мутантный симбиоз*, *Вспышка магмы* и др.).

- 🧪 **Симулятор лаборатории скрещивания (Fusion Chamber):**
  - Математическая модель наследования параметров от родительских девиантов.
  - Расчёт уровней характеристик боевой эффективности (Combat) и активности (Activity).
  - Учёт катализаторов скотоводства (прирученные животные с рангами S/A/B дают множитель x10 к шансу передачи).
  - Использование мутагенов и девиантов-доноров (до 3 слотов реагентов).
  - Пакетная симуляция (10, 50, 100 циклов) для оценки вероятности получения идеального экземпляра («God-Roll»).

- 🔍 **Умный поиск, фильтрация и сравнение:**
  - Быстрые фильтры по ролям в бою (Урон, Поддержка, Контроль), сценариям (The Way of Winter), бункерам и наличию морфов.
  - Двустороннее сравнение характеристик двух девиантов (Compare Mode).
  - Система избранного (Favorites) с сохранением в локальном хранилище браузера.

- ♿ **Доступность (Accessibility / WCAG AAA):**
  - Высококонтрастный режим для людей с особенностями цветовосприятия (протанопия, дейтеранопия, тританопия).

- ⚡ **PWA и Офлайн-режим:**
  - Встроенный Service Worker кэширует ресурсы и позволяет запускать приложение без интернета.
  - Поддержка установки на главный экран смартфона или рабочий стол ПК.

## 📁 Структура проекта

```text
OnceHumanWiki/
├── index.html              # Главная страница (разметка интерфейса, каталог и симулятор)
├── style.css               # Таблицы стилей (тема, адаптивность, анимации, контрастный режим)
├── script.js               # Основной скрипт энциклопедии (поиск, фильтры, модальные окна, морфы)
├── fusion-sim.js           # Логика и математика симулятора лаборатории скрещивания
├── sw.js                   # Service Worker для офлайн-работы и кэширования (PWA)
├── manifest.json           # Манифест PWA-приложения
├── .gitignore              # Исключения для Git
├── README.md               # Документация проекта
├── data/
│   ├── deviants.json       # Полная база всех базовых девиантов, черт и локаций
│   ├── variants.json       # База редких морфов (250+ цветовых форм и пассивок)
│   └── fusion_data.json    # Параметры механики скрещивания и мутагенов
├── icons/                  # Иконки для PWA и фавиконки
└── images/                 # Локальные изображения девиантов и скинов
    └── variants/           # Локальные webp-изображения ключевых морфов
```
